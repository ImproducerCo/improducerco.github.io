Как подключить

Две минуты.

  1. В кабинете — «Подключения» → «Получить код подключения».
  2. В Claude: Настройки → Коннекторы → Добавить свой коннектор. Название — improducer, адрес — https://connect.improducer.co/mcp.
  3. «Подключить» → введите код. Код одноразовый, действует сутки.
  4. Новый чат: «improducer, что дальше?» — Claude откроет вашу систему.

Вопросы

Какой нужен тариф Claude?

Свои коннекторы работают на платных тарифах Claude. Лимит сообщений — ваш, в вашем Claude.

Где взять код подключения?

В кабинете: «Подключения» → «Получить код подключения».

Claude спрашивает разрешение на каждый вопрос

В настройках коннектора, «Разрешения инструментов», поставьте «Разрешать всегда» на обе группы.
